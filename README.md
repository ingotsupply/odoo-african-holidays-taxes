# African Holidays & Taxes for Odoo

Odoo 19 module (`african_holidays_taxes/`): national public holidays of the 54 African countries in Odoo's working
schedules and Time Off, with an optional read-only reference list of VAT, withholding tax and e-invoicing data from the
Africa Compliance Data service. Free, LGPL-3. See `african_holidays_taxes/README.md`.

Branch `19.0` is for Odoo 19.
